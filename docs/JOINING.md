# How to Join the Project

Want to help build AURA BATTLE?

You can propose participation with a normal GitHub Pull Request. No special application system is required.

## Fast path

1. Fork the repository.
2. Create a branch named `join/<your-github-username>`.
3. Add or update a small text file at `contributors/requests/<your-github-username>.md` using the template below.
4. Open a PR against `main`.
5. Use the title `[JOIN] <your-github-username>`.

Template:

```markdown
# Contributor Request

GitHub: @your-username

## I want to help with
- [ ] Luau / gameplay programming
- [ ] Combat
- [ ] NPC / PvE
- [ ] UI/UX
- [ ] Building / map
- [ ] VFX/SFX
- [ ] QA/testing
- [ ] Documentation
- [ ] Design/balance
- [ ] Other: 

## First task I would like to take
Describe one small task.

## Experience
Optional. Beginners are welcome.

## Agreement
I have read `AGENTS.md`, `docs/PROJECT_CHARTER.md`, and `docs/CONTRIBUTING.md` and agree to keep contributions within the project direction.
```

## Important

A join PR is a request to participate, not automatic repository write access. The maintainer decides whether to grant collaborator permissions after review.

You can also skip the join request and directly submit a small contribution PR if you already know what you want to fix/build.
